Dual-Oracle Architecture

1 · Transcript Oracle

Inspects the live CLI event stream during agent execution. Catches phantom artifact declarations, phantom test claims, and verdict assertions on undecidable questions.

2 · Artifact Oracle

Inspects all persistent files written to arena/world/ upon turn completion. Validates syntax, mathematical consistency, test pass claims, and epistemic firewalls.

3 · Immutable Hash Ledger

Every event is chained with SHA-256 outside the agent's writable directory. Deleted files or altered history are immediately detectable at build and verification time.
